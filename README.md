# Demo Aplikasi Kasir — CuciAja & Kasirku

Demo langsung di browser (GitHub Pages), tanpa server:

- **CuciAja** — kasir laundry (order kiloan/satuan, status cucian, DP/lunas, nota, WhatsApp).
- **Kasirku** — kasir toko (penjualan, stok, invoice, laporan, mode offline).

Akun demo: `admin` / `admin123` · `kasir1` / `kasir123`.
Data contoh fiktif dan hanya tersimpan di browser pengunjung.
