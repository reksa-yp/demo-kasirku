PinaPos adalah aplikasi kasir Android yang bisa Anda download dan pakai gratis, tanpa biaya bulanan. Dibuat untuk warung, toko kelontong, dan usaha kecil lain yang butuh kasir sederhana tapi rapi. PinaPos berjalan offline tanpa server dan tanpa internet, jadi kasir tetap jalan walau sinyal hilang.

Fitur PinaPos

  • Kasir cepat: cari produk atau scan barcode, keranjang, diskon, dan pajak.
  • Cetak struk: mendukung kertas thermal 58mm dan 80mm.
  • Stok dan produk: tambah, ubah, dan hapus produk, dengan stok yang berkurang otomatis setiap transaksi.
  • Pembayaran: tunai, transfer, atau QRIS (tinggal unggah gambar QRIS toko Anda).
  • Pelanggan dan invoice: simpan data pelanggan dan cetak invoice A4.
  • Laporan: riwayat transaksi dan dashboard penjualan.
  • Banyak pengguna: Kasir Admin bisa mengatur semua fitur, Kasir biasa hanya untuk transaksi.
  • Identitas toko: logo, nama, alamat, dan warna tema sesuai selera.
  • Bisa dicoba: sudah berisi produk dan transaksi contoh, jadi Anda bisa langsung mencoba semua fitur.

Cara download dan install

  1. Ketuk tombol Download APK PinaPos dari browser HP Android (Chrome).
  2. Di bagian Assets, ketuk file PinaPos-….apk untuk mulai mengunduh.
  3. Setelah selesai, buka file tersebut dari notifikasi atau folder Download.
  4. Jika muncul peringatan, izinkan Instal dari sumber tidak dikenal untuk Chrome atau aplikasi file manager Anda, lalu kembali.
  5. Ketuk Instal dan tunggu sampai selesai.
  6. Jika Play Protect menampilkan peringatan, pilih Detail lainnya, lalu Tetap instal. Peringatan ini muncul karena PinaPos belum tersedia di Play Store.
  7. Ketuk Buka untuk menjalankan PinaPos.

Cara update ke versi baru: hapus PinaPos versi lama, lalu install versi terbaru. Perhatikan bahwa menghapus aplikasi juga menghapus data di dalamnya.

Login pertama dan langkah awal

PinaPos sudah menyediakan akun contoh, jadi Anda bisa langsung masuk setelah install.

PeranUsernamePassword
Kasir Admin (semua fitur)adminadmin123
Kasir (transaksi saja)kasir1kasir123

Setelah masuk sebagai admin, lakukan ini sebelum mulai berjualan:

  1. Ganti password akun admin dan kasir lewat menu akun di pojok kanan atas.
  2. Buka Pengaturan, lalu isi nama usaha, alamat, dan logo toko. Atur juga lebar kertas struk (58mm atau 80mm).
  3. Jika menerima QRIS, unggah gambar QRIS toko Anda di Pengaturan.
  4. Buka Produk, hapus produk contoh, lalu masukkan produk dan stok Anda sendiri.
  5. Coba satu transaksi dan cetak struknya untuk memastikan printer sudah tersambung.

Pertanyaan yang sering ditanyakan

Apakah PinaPos benar-benar gratis?

Ya. Semua fitur bisa dipakai tanpa biaya, tanpa langganan, dan tanpa fitur yang dikunci.

Apakah perlu internet?

Tidak. PinaPos berjalan sepenuhnya offline. Internet hanya dibutuhkan saat mengunduh aplikasi.

Di mana data saya disimpan?

Di HP Anda sendiri, bukan di server orang lain.

Kenapa muncul peringatan saat install?

Karena PinaPos dipasang dari file APK, bukan dari Play Store. Ini wajar untuk aplikasi yang diunduh langsung dari pengembangnya.

Apakah bisa dipakai untuk laundry?

Untuk usaha laundry, kami membuat aplikasi terpisah bernama CuciAja. Download APK CuciAja atau coba dulu demo CuciAja.
