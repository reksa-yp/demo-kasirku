Download APK CuciAja

CuciAja adalah aplikasi kasir laundry Android yang bisa Anda download dan pakai gratis, tanpa biaya bulanan. Catat order kiloan dan satuan, pantau status cucian, cetak nota, dan kabari pelanggan lewat WhatsApp. CuciAja berjalan offline tanpa server dan tanpa internet, jadi kasir tetap jalan walau sinyal hilang.

Fitur CuciAja

  • Order laundry: kiloan dengan berat desimal dan layanan satuan, estimasi selesai otomatis.
  • Status cucian: diterima, dicuci, siap diambil, dan diambil, semua terpantau dari menu Cucian.
  • Pembayaran fleksibel: bayar nanti, DP, atau lunas, plus pengingat cucian yang belum lunas.
  • Nota: cetak nota thermal 58mm atau 80mm.
  • WhatsApp pelanggan: kirim pesan saat cucian diterima dan saat siap diambil.
  • Jual barang: jual deterjen, parfum, atau barang lain dari menu Jual Barang.
  • Layanan dan harga: atur sendiri jenis layanan dan tarifnya.
  • Laporan: riwayat cucian, riwayat penjualan, dan dashboard.
  • Banyak pengguna: Kasir Admin bisa mengatur semua fitur, Kasir biasa hanya untuk transaksi.
  • Bisa dicoba: sudah berisi order dan data contoh, jadi Anda bisa langsung mencoba semua fitur.

Cara download dan install

  1. Ketuk tombol Download APK CuciAja dari browser HP Android (Chrome).
  2. Setelah selesai, buka file CuciAja.apk dari notifikasi atau folder Download.
  3. Jika muncul peringatan, izinkan Instal dari sumber tidak dikenal untuk Chrome atau aplikasi file manager Anda, lalu kembali.
  4. Ketuk Instal dan tunggu sampai selesai.
  5. Jika Play Protect menampilkan peringatan, pilih Detail lainnya, lalu Tetap instal. Peringatan ini muncul karena CuciAja belum tersedia di Play Store.
  6. Ketuk Buka untuk menjalankan CuciAja.

Cara update ke versi baru: hapus CuciAja versi lama, lalu install versi terbaru. Perhatikan bahwa menghapus aplikasi juga menghapus data di dalamnya.

Login pertama dan langkah awal

CuciAja sudah menyediakan akun contoh, jadi Anda bisa langsung masuk setelah install.

PeranUsernamePassword
Kasir Admin (semua fitur)adminadmin123
Kasir (transaksi saja)kasir1kasir123

Setelah masuk sebagai admin, lakukan ini sebelum mulai menerima cucian:

  1. Ganti password akun admin dan kasir lewat menu akun di pojok kanan atas.
  2. Buka Pengaturan, lalu isi nama laundry, alamat, logo, dan teks pesan WhatsApp.
  3. Buka Layanan, lalu sesuaikan jenis layanan dan harganya (kiloan dan satuan).
  4. Tambahkan pelanggan beserta nomor WhatsApp-nya di menu Pelanggan.
  5. Coba satu order dan cetak notanya untuk memastikan printer sudah tersambung.

Pertanyaan yang sering ditanyakan

Apakah CuciAja benar-benar gratis?

Ya. Semua fitur bisa dipakai tanpa biaya, tanpa langganan, dan tanpa fitur yang dikunci.

Apakah perlu internet?

Tidak. CuciAja berjalan sepenuhnya offline. Internet hanya dibutuhkan untuk mengunduh aplikasi dan mengirim pesan WhatsApp ke pelanggan.

Di mana data saya disimpan?

Di HP Anda sendiri, bukan di server orang lain.

Kenapa muncul peringatan saat install?

Karena CuciAja dipasang dari file APK, bukan dari Play Store. Ini wajar untuk aplikasi yang diunduh langsung dari pengembangnya.

Saya punya toko, bukan laundry?
